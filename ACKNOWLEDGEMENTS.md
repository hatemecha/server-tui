# Acknowledgements

server-tui stands on excellent open-source foundations:

- [ratatui](https://github.com/ratatui/ratatui) — terminal UI framework
- [crossterm](https://github.com/crossterm-rs/crossterm) — terminal control
- [sysinfo](https://github.com/GuillaumeGomez/sysinfo) — process/metrics
- [zbus](https://github.com/dbus/zbus) — D-Bus / systemd
- [tokio](https://github.com/tokio-rs/tokio) — async runtime
- [clap](https://github.com/clap-rs/clap) — CLI parsing
- [jwalk](https://github.com/jessegrosjean/jwalk) — parallel directory walk

UX inspiration (patterns only, not copies): btop, bottom, systemctl-tui, lazygit, lnav, ncdu/gdu, Cockpit.
